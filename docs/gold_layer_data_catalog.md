# Data Catalog for Gold Layer

## Overview
The Gold Layer is the business-level data representation, structured to support analytical and reporting use cases. It consists of **dimension tables** and **fact tables**, implemented as views over the Silver layer (`silver.csv_central_superstore`).

---

### 1. **gold.dim_customers**
- **Purpose:** Stores customer identity and location details.
- **Columns:**

| Column Name    | Data Type     | Description                                                                 |
|----------------|---------------|-------------------------------------------------------------------------------|
| customer_key   | NVARCHAR(50)  | Surrogate key uniquely identifying each customer (sourced from customer_id). |
| segment        | NVARCHAR(50)  | The customer segment (e.g., 'Consumer', 'Corporate', 'Home Office').        |
| customer_name  | NVARCHAR(100) | Full name of the customer.                                                  |
| country        | NVARCHAR(50)  | Country of the customer.                                                    |
| state          | NVARCHAR(50)  | State/province of the customer.                                             |
| city           | NVARCHAR(50)  | City of the customer.                                                       |
| postal_code    | NVARCHAR(20)  | Postal/ZIP code of the customer's location.                                 |

---

### 2. **gold.dim_products**
- **Purpose:** Provides product classification details.
- **Columns:**

| Column Name  | Data Type     | Description                                                             |
|--------------|---------------|---------------------------------------------------------------------------|
| product_key  | NVARCHAR(50)  | Surrogate key uniquely identifying each product (sourced from product_id). |
| product_name | NVARCHAR(500) | Descriptive name of the product.                                        |
| category     | NVARCHAR(50)  | High-level product classification (e.g., 'Furniture', 'Technology').   |
| sub_category | NVARCHAR(50)  | More granular classification within the category.                      |

---

### 3. **gold.dim_order_details**
- **Purpose:** Stores order-level shipping and timing attributes.
- **Columns:**

| Column Name        | Data Type    | Description                                                              |
|---------------------|--------------|---------------------------------------------------------------------------|
| order_details_key  | NVARCHAR(50) | Surrogate key uniquely identifying each order (sourced from order_id).  |
| order_date         | DATE         | The date the order was placed.                                          |
| ship_date          | DATE         | The date the order was shipped.                                         |
| ship_mode          | NVARCHAR(50) | The shipping method used (e.g., 'Standard Class', 'First Class').       |

---

### 4. **gold.fact_sales**
- **Purpose:** Stores transactional sales measures for analysis.
- **Columns:**

| Column Name       | Data Type    | Description                                                                 |
|--------------------|--------------|--------------------------------------------------------------------------------|
| sales              | FLOAT        | The line-item sales revenue.                                                |
| quantity           | INT          | Number of units ordered in the line item.                                  |
| total_price        | FLOAT        | Derived total price for the line item (sales × quantity, per silver layer). |
| discount           | FLOAT        | Discount rate applied to the line item.                                    |
| profit             | FLOAT        | Profit generated by the line item.                                         |
| product_key        | NVARCHAR(50) | Foreign key linking to gold.dim_products.                                  |
| customer_key       | NVARCHAR(50) | Foreign key linking to gold.dim_customers.                                 |
| order_details_key  | NVARCHAR(50) | Foreign key linking to gold.dim_order_details.                             |
